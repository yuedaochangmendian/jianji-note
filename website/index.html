它做什么

够用的功能一条不少，用不上的东西一样不加。

  • 离线优先

    笔记存进本机的 Room 数据库，不需要账号，也不经过任何服务器。网络权限只在你自己配置 WebDAV 时才会用到。

  • 十种列表样式

    普通、卡片、网格、摘要、日历、精简、Material、极简、锤子、熊掌记，配三种排序，置顶永远排在最前。

  • 编辑器该有的都有

    撤销重做最多 60 步，工具栏能缩进、待办、引用、分隔线、插入时间日期，支持内嵌图片；停止输入 1.2 秒自动落库，退出时再强制保存一次。

  • Markdown 模式

    一键切换，工具栏变成 H1–H3、加粗、代码块、链接；预览页把解析结果渲染成富文本。

  • 锁得住

    4 位数字应用密码，离开应用自动重新上锁；少数几条不想被看见的笔记，还能单独加锁。

  • 数据你自己拿着

    导出 JSON 备份、单条导出 TXT / Markdown / PDF、分享文本或分享为图片；同步走自己的 WebDAV（坚果云、Nextcloud、自建 NAS）。

  • 长得像你用的

    浅色、深色或跟随系统，6 套强调色，正文字号 12–30sp，行距 1.0–2.5 倍，还能换自定义字体和背景。

  • 桌面小组件

    按文件夹显示笔记列表的小组件，配色、圆角和条数都能调；长按图标有「新建笔记 / 搜索」的快捷方式。
